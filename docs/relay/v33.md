## 5. Item 4: `check:sources`

`scripts/check-sources.mjs`, wired as `pnpm check:sources` and into **both** CI
lanes.

**One detector, not two.** `unsourcedFigures` moved out of
`src/lib/admin/article-draft.ts` into `src/lib/unsourced-figures.mjs`, a
dependency-free leaf module. The pane imports it and re-exports it; the gate
imports it directly. The matching logic is byte-for-byte what `66c67fb` shipped
and only its address changed. This is the arrangement `src/data/redirects.mjs`
already uses for the redirect table, and it exists for the same reason: two
implementations would drift silently, one green on the article the other would
have caught.

The 15 tests in `e2e/article-validation.spec.ts` pass unchanged through the
re-export, which is the proof the pane still sees the same rule.

**Drafts are exempt, published insights are not.** An article with no
`published` key at all counts as published, matching what the manifest and the
route layer do with it.

**THE TRIVIAL-PASS COUNT, ON THE REAL TREE: 0 published insights checked, 21
drafts exempt.** Every insight in the corpus is `published: false`, so the gate
finds nothing to fail on and could not, tonight, tell a working detector from a
broken one. That is exactly why the fixture is not optional.

**Red-proven twice, both watched:**

1. By hand: a published `.mdx` carrying `63%` and `1,400` with no `sources`
   block gave **exit 1**, naming both figures. Deleting it gave **exit 0**.
2. By the gate itself: `--selftest` writes a real fixture `.mdx` into
   `content/insights/`, asserts it fails on both unsourced figures **and** that
   the one figure with a matching `sources` entry is spared, then removes it.
   **Exit 0**, fixture gone, `git status` on `content/` clean afterwards.

The fixture is a real file rather than an in-memory object because the reading,
the frontmatter parse and the published filter can each be wrong, and an
in-memory fixture proves none of them. Teardown runs on the normal path, on a
throw, and on `SIGINT` and `SIGTERM`. **The signal path is wired but was not
exercised.** The fixture exists for a few milliseconds and the race could not
be won honestly. The normal path and the failing path were both watched.

CI runs `--selftest`, not the bare gate, in both lanes: a checker that has gone
blind must not be able to pass by finding nothing.
