### §2.1 The terminology lint, gate first then copy, in that order

**The diagnosis, which was the first thing asked for: it is a RULE gap, not a
coverage gap.** `src/app/why-yallo/page.tsx` was being read the whole time — the
lint's ROOTS are `src` and `content`, and `.tsx` is in its EXTS. Neither
"operator" nor the em dash was in the rule set at all. The em-dash rule has been
restated in four separate ruling documents and existed in none of them as anything

**One correction to §2.1's premise, and it changes nothing about the ruling.**
"operator" is described there as being on "the standing banned AI-tell list in
canon". **There is no such list.** Canon §2's banned-abstraction list does not
contain the word, and nothing in the repository matches "AI-tell". The ban is this
round's own §2.5 ruling, which is authority enough. Recorded in the rule's
provenance so a later round does not go hunting for a list that was never there.

**The gate** (`c745ec3`), committed red on 228 occurrences before any copy moved.
Rules are data now, in `src/lib/copy-rules.json`, each with its provenance beside
it — because one of these two turned out to be misattributed, so the file that
holds them records where each came from.

**Copy rules are separate from source rules, and that is the design decision worth
reading.** Everything already in the lint scans raw source lines, which is right
for "GCC": a wrong geography in a comment is still wrong. An em dash in a comment
is not a defect. Measured: **1384 em dashes in the trees the lint reads, 271 of
them in copy.** A source-level ban meant rewriting a thousand comments to enforce a
rule about prose a buyer reads, and the pressure to then narrow the rule until the
run looked small is what §3 forbids. Scoping to copy is not narrowing the rule; a
comment was never copy.

**The scanner reads whole files, not lines, and the first version did not.** It
matched JSX text as `>text<`, which needs the tag and the text on one line. The H2
that opened this round —

```
<h2 className={styles.sectionH}>
  Operators who ran the programmes you're running.
</h2>
```

— puts the text on its own line, so **the gate written to catch it missed it.**
Found by grepping for the H2 in the gate's own output and getting nothing. Offsets
now map back to line numbers past the leading whitespace, so a hit points at the
line the text is on.

**The copy fix** (`0dd4f26`): **242 em dashes across 56 files, 22 "operator"
across 15.** `check:terms` exits 0 on 295 files with both rules live.

Every "operator" resolved occurrence by occurrence, canon §2's standing method:
Yallo's people and screening take the ratified specialist language, and where a
sentence could say what is CHECKED rather than who checks it, it now does — "Built
by operators, not recruiters" became "Screened to a delivery standard, not a
keyword match". Two capability overviews used the noun for a real skill and now use
the verb. `/industries/education`'s "multi-school operators" are a client type and

**Reading the diff caught six real bugs the script could not see**, all one class:
