## Open items, each with its unblocking question

1. **`check-gate-coverage.mjs` over-credits `check-a11y`.** Severity **low, but
   the class is the one this build keeps paying for.** `listOf()` tests
   `fetchPublishedPaths(` before `sampleOnePerShell(`; `check-a11y.mjs` contains
   both, so the line added for it never executes and it is credited with every
   published URL instead of its per-shell sample. Inert today — both resolve to
   the same shell set — and wrong the day someone changes what its default run
   visits. *Unblocking question: reorder the two branches in round 16, or leave
   it and rely on the shell-set equivalence?*
2. **`check-assistant-terms` reports green on the error path.** Severity
   **medium.** On the invalid-key run it printed "No banned terminology in 3
   sampled generated replies" while all three "replies" were the 502 error
   string. It never reached the model and said nothing about it — the exact
   failure `check-assistant-a11y`'s docstring guards against and this one does
   not. *Unblocking question: should it fail, or warn, when a sampled reply is
   an error response?*
3. **`build-logos.mjs:86`'s comment names the wrong source file.** Severity
   **trivial.** Says the arrived Blue Yonder source is `BlueYonder.png`; the map
   reads `BlueYonder-icon.jpeg`. *Unblocking question: fold into round 16's
   first commit?*
4. **`.env.local` in the main checkout has empty `RESEND_FROM` and
   `RESEND_TO` keys** — present as bare names with no values, so the code
   defaults do the work. Matches §5.6. *Unblocking question: delete the two
   empty lines, or set them explicitly before cutover?*
