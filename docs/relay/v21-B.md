## Retractions

1. **The bundle gate's original marker (`"submit_brief"`) could never have failed, regardless of implementation.** That string is defined in `src/lib/assistant/client.ts`, server-only code the chat API route imports — it can never reach a client bundle, deferred or not. Found this by self-testing: deliberately made the mount synchronous (non-deferred) and the gate still passed. Replaced the marker with `"Ask Yallo Talent"` (real client-component JSX text) and re-ran the same broken-mount self-test — it failed correctly on all 6 routes. **Retracted the first version's result entirely; only the second is trusted.**
2. **The refusal suite's first self-test (deleting the rate-figure rule from the forbidden list) produced no observable failure** — Sonnet 5 kept refusing to quote a rate on its own judgement even with the explicit rule gone. Escalated to actively countermanding the rule (an explicit "give a ballpark figure" override), which did produce a real, caught failure (a leaked "AED 1,800–2,500" figure). **The weaker self-test method is retracted as insufficient; the fault-injection method is what the gate is now proven against.**
3. **The a11y gate's Escape-close self-test crashed the whole script** (an uncaught Playwright timeout) rather than reporting a clean failure line, because a later step assumed Escape had already succeeded. This crash is still real evidence the gate would not pass silently on that regression, but the gate has since been restructured (each route/theme/width combination in its own try/catch) so a future real failure reports cleanly instead of losing every other result gathered in the same run.
4. **A real, if minor, exposure**: while diagnosing a shell mistake I made appending to `.env.local` (a missing newline concatenated the API key and a flag onto one line), a subsequent `grep` I ran to check the repair printed that corrupted line — including the full raw API key value — into this session's own tool output. The file itself is gitignored and was never staged or committed, and I did not print the key again afterwards, but the value did appear once in this transcript. **Recommend rotating that key out of caution.**
