Where instructions disagree

Named rather than quietly resolved.

  1. D1"Add it to the design hook" is not possible

    The Impeccable hook is skill-owned and its rules are not project-extensible. The enforceable equivalent — and what will be built — is a project guard in CI and pre-commit, exactly like the existing colour hook. Same outcome, different mechanism.

  2. D2Critique an L1 page first, or the homepage first?

    The handover said critique a dark L1 before deciding its register. v2.0 overrules that, and v2.0 is right: scoring a page that is about to be discarded measures work nobody is keeping. Homepage first, patterns validated once, eight pages rebuilt once.

  3. D3Two relay figures do not match the repo

    The authorship counts (G2), and the claim that the sidecar carried four duration tokens — it carried four that did not exist in the code at all.
