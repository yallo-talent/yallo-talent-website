# Relays

Relays v1.0 to v6.0, and the code-to-code handover, live in this folder.

**Relay v7.0 is at [`docs/relay/code-to-chat-v7.0.md`](../relay/code-to-chat-v7.0.md)**,
which is the path its dispatch named. Note the folder is `relay`, singular.

Two folders one character apart is a trap. Before v8.0 is written, one of them
should be chosen as canonical and the other emptied into it. This file exists so
that nobody looking for the latest relay in the obvious place concludes there
isn't one.
