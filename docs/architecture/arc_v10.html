All Confirmed Decisions

Locked. Build from these.

Every design, content and architecture decision confirmed by Raphy before build. Nothing in this document is an assumption.

✓ Confirmed
Two-level taxonomy only. No L3.
L0 = hubs. L1 = sector/platform/capability pages. L2 = function pages with full tool detail on-page. No deeper pages. Tool vendors live as cards on the L2 page — not their own routes.
✓ Confirmed
Contract-first audience. Language matches.
Primary buyer: Programme Manager / IT Director with an open contract seat and a deadline. Every CTA reads "Request a contractor →". Speed signals (72h) and availability signals dominate. Permanent placement is secondary.
✓ Confirmed
Role-dominant cards. Logo as reference badge.
Vendor logo is a small badge top-left — a familiarity signal for domain visitors. Role titles are the dominant visual element inside each card. 4–5 contractor role pills per card. This is what the hiring leader scans for first.
✓ Confirmed
Sector-level hero image on L2 pages.
One hero image per sector (e.g. retail trading floor), applied consistently across all L2 pages within that sector. The H1 and breadcrumb provide function-level specificity. No need for per-function photography.
✓ Confirmed
Sticky left sidebar on L2 — all functions listed.
Shows all L2 function pages for that sector. Active item: amber left-border + highlighted. Serves dual purpose: navigation + credibility signal (visitor sees full sector coverage at a glance).
✓ Confirmed
UK · ME · India — in that order. No GCC.
Applied consistently across: hero stats, meta descriptions, card bench signals, JSON-LD LocalBusiness schema, footer, and all content copy. ME = Middle East. Never GCC.
✓ Confirmed
L1 page: different approach from L2. No sidebar.
L1 (/industries/retail) is a sector landing page. Full-bleed hero. Function categories as image-led cards in a grid. Each card links to its L2 page. Confident and broad — no sidebar clutter at this level.
✓ Confirmed
Content shift: stop describing tools, deploy talent.
No vendor marketing copy. No "SAP CX delivers real-time data insights." Only: what roles Yallo places, how screening works, why the contractor has implementation depth. The visitor already knows what the tool is.

Content Rules — Contract-First Voice

What to write. What never to write.

Every page on the site speaks to a contract hiring leader who already knows the technology. These are the rules Tanzil follows for every content file.

✓ Write this — contractor-framed
  • "Finding SAP EWM contractors who have delivered in live retail environments is harder than it looks."
  • "Every contractor on our bench is assessed for implementation depth — not just platform certification."
  • "Contract, EOR or subcontracted — matched to how you need to hold the risk."
  • "We return a shortlist within 72 hours of the brief."
  • "Contractor roles we deploy in this function:" (then role titles — not job descriptions)
  • Specific role titles: "SAP CX Functional Consultant" not "SAP specialists"
✗ Never write this — vendor marketing voice
  • "SAP Customer Experience delivers personalised experiences using real-time data insights."
  • "Salesforce Marketing Cloud drives engagement with scalable customer-centric marketing tools."
  • "Our world-class specialists deliver excellence across enterprise technology platforms."
  • Any sentence that describes what the tool does — not what Yallo deploys
  • Generic claims: "We have the best talent" without specifics
  • Pricing, rate cards, or fee references of any kind
✓ H1 patterns that convert
  • "Customer Experience contractors, deployed in 72 hours."
  • "SAP EWM specialists for retail programmes — contract and EOR."
  • "Salesforce Marketing Cloud contractors. Architect-screened. Available now."
  • Formula: [Function/tool] + contractors + speed or availability signal
  • Never: "[Function] Management — Yallo's Expertise" (brochure language)
✓ Vendor card copy rules
  • Logo: small badge (monochrome) — reference signal only, not hero
  • Tool name: large, bold, white — the anchor
  • Label: "Contractor roles" in DM Mono amber — explicit
  • Roles: 4–6 specific contractor titles as pills — DOMINANT visual
  • Bench signal: green dot + "Active bench · UK · ME · India"
  • CTA: "Request a contractor →" — not "Find a specialist" or "Learn more"
