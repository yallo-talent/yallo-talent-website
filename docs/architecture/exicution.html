# Colour hook — enforces no hardcoded hex in components
cat > .claude/hooks/check-colours.js << 'EOF'
const fs = require('fs'), path = require('path')
const HEX = /#([0-9a-fA-F]{3,8})\b/g
const dirs = ['src/components','src/app']
let fail = false
dirs.forEach(d => {
  if(!fs.existsSync(d)) return
  fs.readdirSync(d,{recursive:true}).forEach(f => {
    if(!/\.(tsx|css)$/.test(f)) return
    const full = path.join(d,f), src = fs.readFileSync(full,'utf8')
    if(HEX.test(src)) {
      console.error(`COLOUR GATE: hardcoded hex in ${full}`)
      fail = true
    }
  })
})
if(fail) process.exit(1)
EOF

Design System — Breaking the Usual Patterns

Not a typical recruitment site.
Emil Kovacs standard throughout.

Contract hiring managers are CIOs, IT Directors and Programme Managers. They visit Michael Page, Korn Ferry, Robert Half daily. Yallo needs to feel categorically different — premium, editorial, confident. These are the rules that achieve it.

Pattern-breaking design rules — the Emil Kovacs list

Break rule 01
Oversized display type on dark sections
H1 at 5–6vw, letter-spacing –3px, weight 800. Text fills its container — not padded away from edges. Hiring leaders in the GCC respond to confidence signals. Small type feels like a small company.
font-size: clamp(38px, 5.5vw, 72px); letter-spacing: -0.04em;
Break rule 02
Asymmetric grid — 7:5, not 1:1
Avoid the equal-column trap. The "how it works" section uses 7 columns for the content, 5 for the visual callout. The sector grid uses 4-wide on desktop, breaking to 2+1 on mid. Nothing is perfectly centred at large viewport.
grid-template-columns: 7fr 5fr; /* not 1fr 1fr */
Break rule 03
Horizontal scroll for role pills
Role pill strips on L2 pages and the homepage talent section scroll horizontally on mobile rather than wrapping into an ugly block. On desktop they display as a wrapping flex. Horizontal scroll signals depth — more than you can see at once.
overflow-x: auto; scroll-snap-type: x mandatory; white-space: nowrap;
Break rule 04
Noise texture on dark hero sections
A subtle SVG noise overlay (opacity 0.03) on the hero and dark CTA sections adds tactility and stops the flat dark background feeling like a void. One CSS filter, zero performance cost. The difference between premium and generic.
background-image: url('/images/noise.svg'); background-blend-mode: overlay;
Break rule 05
Magnetic CTA hover effect
The primary "Request a contractor →" button tracks the cursor position slightly (–6px to +6px translate) on hover. Framer Motion useMotionValue + useSpring. Feels premium and interactive. Only on desktop — touch devices get standard hover state.
const x = useSpring(useMotionValue(0), {stiffness:150,damping:15})
Break rule 06
Left-border glow on card hover
Vendor cards and expertise cards use a 3px amber left-border that is invisible at rest and fades in on hover alongside a 4px translateY lift. No box-shadow theatrics — one precise amber line signals selection. Emil Kovacs' most consistent pattern.
border-left: 3px solid transparent; &:hover { border-left-color: var(--accent); }
Break rule 07
Exposed dot-grid on dark sections
A radial-gradient dot pattern (rgba(255,255,255,.03), 20px × 20px) covers dark hero and CTA sections. Too subtle to notice directly, impossible to miss when removed. It gives depth without images and signals craft to anyone who pays attention.
background-image: radial-gradient(rgba(255,255,255,.03) 1px, transparent 1px); background-size: 20px 20px;
Break rule 08
Scroll-triggered number counters
Stats (72h, 2:1, 3 regions) animate from zero when they enter the viewport. Framer Motion useInView + a count-up function. DM Mono font for numbers — monospaced numbers prevent layout shift during count. Counters stop on prefers-reduced-motion.
const count = useMotionValue(0); animate(count, target, {duration:1.4})

Animation Specification

Every animation. Every section.
Performance budget enforced.

Ken Burns on the hero. Parallax on inner blocks. Scroll-reveal on content. All animations run under 16ms per frame. prefers-reduced-motion respected globally in L6 of globals.css.

Hero
Ken Burns Slider
5 full-bleed slides. Each slide: CSS animation `ken-burns-1` or `ken-burns-2` (alternating), 8s duration, ease-in-out. Framer Motion AnimatePresence handles crossfade (opacity 0→1, 0.8s). Auto-advance 6s. Pause on hover. next/image with priority on slide 1. WebP, 1920px. Dark overlay gradient bottom-up.
→ GPU composited · zero layout shift · LCP <2.5s target
Homepage
Logo Cloud Marquee
CSS-only infinite horizontal scroll. Two identical sets of logos in one row, translateX(0→-50%) at 35s linear infinite. No JavaScript. No Framer Motion. Pauses on hover via animation-play-state. Monochrome logos (filter: brightness(0) invert(1) opacity(.45)).
→ CSS only · zero JS · no reflow
Homepage
Stats Counter
Framer Motion useInView triggers when stat strip enters viewport (once:true). DM Mono numbers animate from 0 to target via animate(count, target, {duration:1.4, ease:'easeOut'}). Formatted with useTransform. Stops on prefers-reduced-motion — shows final value immediately.
→ Runs once · no repeat · 60fps smooth
All pages
Scroll Reveal
Framer Motion motion.div with variants: hidden={opacity:0, y:24}, visible={opacity:1, y:0}. useInView(ref,{once:true,margin:'-80px'}). Duration 0.5s, ease [0.2,0.8,0.2,1]. Applied to: section intros, card grids, vendor cards, expertise cards. Stagger 0.06s between grid items.
→ once:true · no scroll janks · GPU opacity+transform only
Inner blocks
Parallax Sections
Framer Motion useScroll + useTransform on the Problem section and the screening callout block. Background image moves at 0.4× scroll rate. Text moves at 1× (normal). Creates depth without 3D transforms. Only on desktop (window.innerWidth > 768). Disabled on mobile.
→ will-change:transform · desktop only · no scroll blocking
Cards
Magnetic CTA Button
Primary CTA "Request a contractor →" uses Framer Motion useMotionValue for x,y tracking. useSpring({stiffness:150,damping:15}) smooths movement. On mouseleave: spring back to 0. Max displacement ±8px. Only fires on the primary amber button — not secondary CTAs. Desktop only.
→ spring physics · GPU transform · no layout change
L2 Sidebar
Active Item Highlight
Framer Motion layoutId="sidebar-indicator" shared layout animation. As user scrolls and the active section changes, the amber left-border indicator slides smoothly to the new active item. No CSS transitions — Framer layout animation handles it. Feels native, not scripted.
→ shared layout · 0ms perceived lag · smooth
Nav
Scroll Transform
Nav starts at height 72px, background transparent. After 80px scroll: height reduces to 60px, background rgba(8,8,8,.97) with backdrop-filter:blur(20px), border-bottom appears. Framer Motion useScroll + useTransform. Smooth, not jarring. The amber CTA button always stays visible.
→ CSS composited · no paint · 60fps
Problem section
Persona Cycle (home-3 pattern)
Five persona cards (CHRO, CIO, Head of Talent, Delivery Director, CFO) cycle auto on 3s interval. Active card: scale 1.02, amber left border, opacity 1. Inactive: scale 1, opacity 0.5. Framer Motion AnimatePresence + layoutId per card. Click to select manually.
→ Framer layout · smooth reorder · no FOUC

Sumeet's Vision — Planted in Every Page

The mission isn't stated.
It's felt in every interaction.

Sumeet's vision from his operator experience at Richemont, Landmark Group and Alshaya across EMEA: enterprise tech programmes fail because of people, not technology. The right contractor in the right seat changes the outcome. Yallo exists to close that gap.

Mission
Put the right specialist in the right seat, fast.
Not the most available contractor. Not the nearest keyword match. The one who has run this specific programme, on this specific platform, under this specific kind of pressure. That contractor changes the outcome.
Vision
Architect-vetted talent as the standard — not the exception.
Every enterprise technology programme across the UK, ME and India should have access to contractors who have been assessed by people who have done the work. Not CVs. Not keywords. Programme track records.
What this means for the site
Every page earns the booking call.
The hiring leader who lands on a Yallo L2 page should leave thinking: "these people understand what I'm trying to do." Not: "another recruitment agency." That is the design brief. That is the content brief. That is the positioning brief.
